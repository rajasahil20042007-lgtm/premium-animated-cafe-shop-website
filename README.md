# ☕ AURA — Premium Animated Café Shop Website

A state-of-the-art, responsive animated website for an artisanal specialty coffeehouse, roastery, and French viennoiserie atelier.

![AURA Roastery & Café Banner](https://raw.githubusercontent.com/rajasahil20042007-lgtm/premium-animated-cafe-shop-website/main/modular_src/assets/hero_latte.jpg)

---

## 🌟 Key Features

1. **🌿 Dual "Farm-to-Cup" Background Animations**:
   - **Left Wing**: High-altitude cocoa & coffee cherry tree harvest, African bed sun-drying, mountain delivery transit, and roastery storefront delivery.
   - **Right Wing**: Precision 205μm burr grinding, 93.5°C gooseneck kettle pour & bloom, golden amber extraction drip, and steaming velvet crema cup.
2. **☕ Artisanal Menu with Indian Rupee (₹) Pricing & 5% GST**.
3. **🎵 Web Audio API Cozy Café Soundscape Synthesizer** (Coffeehouse acoustic warmth & gentle rain).
4. **🧪 Interactive Brew Lab Ratio & Dose Calculator** (V60, French Press, AeroPress, Cold Brew with live circular extraction countdown timer).
5. **📅 Interactive Table Reservation Booking System** (Party size, date picker, time slot pills, and 4 seating zones).
6. **🛍️ Slide-Out Cart Drawer & Celebration Confetti Order Receipt**.

## 🚀 Live Demo (GitHub Pages)

To view this live website on GitHub Pages:
1. Go to repository **Settings** ➔ **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Set branch to **`main`** and folder to **`/ (root)`**, then click **Save**.
4. Your website will be live at:
   👉 **`https://rajasahil20042007-lgtm.github.io/premium-animated-cafe-shop-website/`**
